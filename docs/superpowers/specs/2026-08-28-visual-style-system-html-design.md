# WordClash 独立视觉规范页设计说明

更新时间：2026-08-28

## 目标

为项目建立一份独立的静态 HTML 规范页，用更低的 token 成本先确认整体界面风格，再按这份基线逐步应用到真实页面中。

本次产出不是业务页面，也不是演示页，而是后续所有 UI 改造的视觉参照。

## 已确认方向

- 形式：独立 HTML
- 定位：纯设计系统基准页
- 风格：更极简克制
- 用途：后续映射到项目中的全局令牌、基础组件和页面骨架

## 核心决策

### 1. 视觉气质

统一为以下关键词：

- 克制
- 清晰
- 安静
- 轻专业
- 信息优先

不走强营销感，也不走过强游戏化视觉。

### 2. 颜色策略

- 配色参考 `https://www.radix-ui.com/colors`
- 中性色优先使用 `slate` 色阶，建立背景、表层、边框和文本层级
- 主品牌色使用 `blue` 色阶，用于主操作、焦点态、轻标签
- 成功 / 警告 / 危险分别参考 `green` / `amber` / `red`
- 状态色同时区分为 `solid`、`soft`、`text` 三类语义，而不是只保留一个十六进制值

当前规范页中的主要映射为：

- 背景：`slate-1`
- 弱背景：`slate-2`
- 弱强调背景：`slate-3`
- 主文本：`slate-12`
- 次级文本：`slate-11`
- 弱文本：`slate-10`
- 边框：`slate-6`
- 主品牌：`blue-9`
- 主品牌文本：`blue-11`
- 成功：`green-9 / green-11`
- 警告：`amber-9 / amber-11`
- 危险：`red-9 / red-11`

### 3. 结构策略

规范页本身采用：

- 左侧目录导航
- 右侧内容区块

这样可以在不模拟业务页面的前提下，清楚展示所有设计规则。

### 4. 展示范围

规范页包含以下模块：

1. 设计原则
2. 颜色体系
3. 排版层级
4. 间距与圆角
5. 操作组件
6. 标签与提示
7. 卡片、列表与空状态
8. 项目落地建议

### 5. 与现有项目的关系

本次规范页不直接改动业务页面，但会作为后续改版基线：

- 保留现有“工作台式”页面组织方式
- 收敛当前偏强的视觉装饰感
- 统一语义令牌命名
- 颜色语义与 Radix Colors 对齐，减少后续再次调色的成本
- 优先把按钮、表单、提示、卡片这些基础层做一致

## 后续建议顺序

建议后续应用到项目时按这个顺序推进：

1. 调整全局设计令牌
2. 统一基础组件样式
3. 收敛侧边导航视觉权重
4. 逐页迁移录入页、阅读页、单词库和分析页

这样可以在不大面积返工的前提下，稳定把新风格落到整个项目中。
